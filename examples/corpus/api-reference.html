REST API Reference

The Beacon REST API lets you manage flags, environments and segments programmatically. All endpoints live under /api/v2 on beacon-server.

Authentication

Authenticate every request with a personal access token in the Authorization header, using the format Authorization: Bearer <token>. Tokens are created under Account > Access tokens and can be scoped to read-only or read-write.

SDK keys cannot be used with the REST API; they only work for flag evaluation.

Rate limits

The REST API allows 300 requests per minute per access token. Requests beyond the limit receive HTTP 429 with a Retry-After header giving the number of seconds to wait. Flag evaluation by SDKs is not rate limited because it happens locally.

Endpoints

List flags

GET /api/v2/projects/{project}/flags returns flags in pages of 50. Pass the cursor value from the previous response to fetch the next page.

Toggle a flag

PATCH /api/v2/projects/{project}/flags/{flag}/environments/{env} with the body {"on": true} switches a flag on in one environment. Every change is recorded in the audit log with the token owner as the actor.

Delete a flag

DELETE /api/v2/projects/{project}/flags/{flag} archives the flag. Archived flags can be restored for 30 days, after which they are permanently deleted.
